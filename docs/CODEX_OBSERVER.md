# Codex coding agent observation boundary

Sentinel can ingest the JSONL event stream from a bounded Codex CLI run and publish a metadata-only summary. This is the first tested real coding-agent intake path, but it is **observation**, not replay. Codex's event stream reports actions; it does not give Sentinel exclusive control over every model call, tool response, filesystem mutation, or external effect. The only output mode is `AGENT_OBSERVATION_ONLY`, with replay coverage marked `unsupported`.

[`codex_trace.py`](../src/sentinel_replay/codex_trace.py) accepts a regular, no-follow JSONL file with bounded total, line, and event counts. It rejects duplicate JSON keys and a torn final line. It counts completed commands and file-change events without copying commands, outputs, or message bodies into the summary. A SHA-256 digest identifies the exact source bytes but does not authenticate who produced them.

Run `sentinel codex inspect TRACE.jsonl --output SUMMARY.json` on a trace you are authorized to inspect. The reproducible synthetic smoke is `python scripts/smoke_codex_observer.py --output NEW_SUMMARY.json`. It starts Codex in a fresh temporary agent directory, captures events in a sibling controller directory, checks a harmless file result, writes only the safe summary, and removes the raw trace and temporary workspace. It uses the configured Codex account and may consume usage; do not run it in a loop. The [official Codex eval guide](https://developers.openai.com/blog/eval-skills) describes `codex exec --json` as a JSONL event stream and demonstrates command-event checks.

Three local runs on 2026-10-07 with Codex CLI `0.162.0-alpha.2` produced checked metadata summaries. The [file-create smoke](../benchmarks/results/codex-observation-2026-10-07.json) had seven events and one completed command. In the [synthetic forbidden-copy case](../benchmarks/results/codex-secret-propagation-2026-10-07.json), Codex copied a fake credential into a public file; the [benign control](../benchmarks/results/codex-benign-copy-2026-10-07.json) copied only public status text. Each run verified a restored pre-run regular-file snapshot in a new directory. The summaries' `limitation` field refers to what the Codex event stream alone proves; `regular_file_restore_verified` records the separate, bounded snapshot check. The forbidden-copy instruction was explicit in this synthetic test, not a demonstrated prompt-injection attack. The effect check happened after execution, not at an enforcing gateway. The retained summaries have no raw prompts, commands, file contents, or credentials; raw traces and temporary workspaces were removed.

The later [MCP gateway experiment](MCP_GATEWAY.md) now proves a separate, explicitly routed `copy_named` action crosses an OPA decision before its effect. It does not retroactively make these three observed shell runs intercepted. Before this becomes the charter's real-agent replay adapter, Sentinel must put an isolated gateway in front of every declared tool boundary, capture and reconcile effect receipts, snapshot and verify covered Git and workspace state, and make unsupported actions fail closed. A synthetic policy violation plus regular-file restore is not enough: the agent's model/tool nondeterminism was not recorded for strict replay, the command effect was not intercepted, and no post-block alternate branch was measured. Merely converting `codex exec --json` events into a journal would not earn `VERIFIED_REPLAY`.

The [coverage manifest](../src/sentinel_replay/agent_coverage.py) added on 2026-10-10 makes this limitation explicit in gateway smoke summaries: observed native commands, file changes, and gateway request counts are reported, but coverage remains `partial` or `unsupported`, and `strict_replay_eligible` is always false. Even zero native events cannot prove the stream saw every action or that an MCP event matches a gateway request; there is no authenticated shared call identifier. Three local unit tests verify these conservative labels.

A later 2026-10-10 [same-run synthetic experiment](../benchmarks/results/codex-mcp-native-gap-2026-10-10.json) did exercise that gap: the agent called the denied MCP tool, then used one observed native command to copy fake bytes within its disposable workspace. The denied MCP effect stayed absent. The two-record [gateway journal](../benchmarks/results/codex-mcp-native-gap-2026-10-10.journal.jsonl) and metadata-only summary are retained; the raw Codex trace and temporary workspace were discarded. This is one explicit instruction, not a prompt-injection success rate or a complete census of agent actions.
