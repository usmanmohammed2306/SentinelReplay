# Performance evidence, not performance theater

Measured on 2026-10-10, local macOS 26.6 / arm64 / Python 3.12.14, 10 logical CPUs. These are **synthetic public-metadata component workloads**, not real-agent incident throughput, API latency, concurrent service capacity, or V1 release measurements. Each trial starts in a fresh Python process and constructs an exact 50,000-record, 16,616,674-byte hash-chained journal. All compared trials produced the same root, one benign timeline phase, and 49,999 **chronological** provenance edges (not causal detections).

**Source-revision boundary (checked 2026-10-10):** Both retained 50K reports bind the measured `journal.py` bytes to `sha256:4500004a13af2f42c5f70dac82e7f65c33f9ba444855edefe635e64b3dceec50`. The current [`journal.py`](../src/sentinel_replay/journal.py) hashes to `sha256:7db379d869689761de2c4d99d69a1fdcc80308f7266c4d4d67edb0d57c7e08ff` after later gateway effect-intent/reconciliation work. The benchmark and comparison scripts still match the digests retained in the reports, but the journal source does not. Consequently the 29.65% RSS comparison and 50K throughput figures are **historical measurements of the recorded source revision**, not measurements of the current checkout or its gateway grammar. The raw reports are preserved unchanged; no benchmark was rerun for this correction.

## What changed

[`Journal.append_many`](../src/sentinel_replay/journal.py) validates and encodes the entire batch before any write, then fsyncs the completed append. The former implementation joined every encoded row into one additional full-batch byte string. The chunked implementation measured in the retained report wrote joins of at most 1,024 rows. That revision removed the second full-batch allocation without changing the measured journal root. A crash during the physical write could still leave a torn tail; recovery was not solved by this optimization.

The [balanced A/B artifact](../benchmarks/results/journal-batch-chunked-comparison-2026-10-10.json) contains all ten raw trials, source digests, environment, and the [benchmark-only reconstruction](../benchmarks/compare_journal_batch.py) of the former joined-write method. Five fresh-process trials per strategy alternated order. Median peak **whole-process** RSS fell from **67,190,784 to 47,267,840 bytes (29.65%)**. Median batch append time was **0.499677 s** for the reconstructed former writer and **0.502579 s** for the chunked writer. That ~0.6% difference is not a demonstrated speed improvement; the useful result is lower peak memory at similar measured append time. The reference is reconstructed, not a checkout of a historical commit. RSS covers append, verification, timeline, and graph construction together, so it is not an allocation profile of `append_many` alone.

The independent [repeated then-current-path artifact](../benchmarks/results/journal-scale-chunked-repeated-2026-10-10.json) contains five fresh-process trials each of batch and per-event durable-stream writing, in balanced alternating order. Median batch append was **0.490099 s (102,020 records/s)**; median chain verification was **0.546619 s (91,471 records/s)**. Median per-event durable-stream append was **1.652650 s (30,254 records/s)**. These modes have different durability granularity and must not be presented as interchangeable. Single-run 2026-10-07 probes and the earlier 2026-10-10 joined/writelines exploratory artifacts remain separate historical observations.

To run a **new** A/B test on the current checkout, use `UV_CACHE_DIR=.uv-cache .venv/bin/uv run --frozen python benchmarks/compare_journal_batch.py --events 50000 --trials 5 --output /tmp/sentinel-batch-comparison.json`. For a new throughput run, use `UV_CACHE_DIR=.uv-cache .venv/bin/uv run --frozen python benchmarks/repeat_journal_scale.py --events 50000 --trials 5 --output /tmp/sentinel-scale.json`. These commands are not a reproduction of the historical source digest; any new result must retain its own source binding and denominator. Both commands write raw per-trial JSON and reject changing journal roots or environments. `UV_OFFLINE=1 make check` verifies semantics and the benchmark runners; the benchmark-session check passed **123 local tests**. The retained artifacts bind the measured journal and benchmark source digests. No remote CI run is claimed.

## Evidence limits

The figures measure one synthetic journal fixture at the recorded source revision. They do not measure production agent traffic, model/tool-call throughput, or p95 latency. The raw reports retain the benchmark method and source identities needed to interpret them.

Scenario-level incident prevention and benign disruption on the frozen twelve-scenario corpus, independently labeled provenance F1, verified restoration/replay fidelity, and real-agent covered-boundary overhead remain unmeasured. Their denominators and failure cases must be published before any percentage is quoted.
